# LegalEase: AI-Powered Legal Document Generator

B.Sc. Computer Science academic project using Python Flask and SQLite.

## Run
1. Install Python 3.x.
2. Open a terminal in this folder.
3. Run `pip install -r requirements.txt`
4. Run `python app.py`
5. Open http://127.0.0.1:5000/

This is an educational prototype. Generated documents should be reviewed by a qualified legal professional before real-world use.
